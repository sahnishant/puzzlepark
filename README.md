# PuzzlePark

Welcome to **PuzzlePark**, a collection of fun and interactive puzzles and games designed to challenge your mind and improve your skills. From classic puzzles to modern games, PuzzlePark offers a variety of experiences for players of all ages.

---

## Features

- **Typing Speed Test**: Test your typing speed and accuracy with real-time feedback and dynamic WPM calculation.
- **Minesweeper**: A grid-based bomb avoidance game with multiple difficulty levels.
- **Word Scramble**: Unscramble the letters to guess the correct word.
- **Number Guessing**: Challenge yourself to guess the correct number within a limited range.
- **Memory Game**: Test your memory by matching pairs of cards.
- **Sudoku**: Solve classic Sudoku puzzles with varying difficulty levels.
- **Tic-Tac-Toe**: Play the classic game against a friend or an AI.
- **Sliding Puzzle**: Rearrange the tiles to complete the picture or pattern.
- **Snake and Ladder**: A digital version of the classic board game.
- **Typing Tutor**: Improve your typing skills with guided lessons.

## Games Overview#
### Typing Speed Test
-Objective: Type the display-ed paragraph as quickly and accurately as possible.
- Features:
Real-time feedback with correct letters highlighted in green and incorrect ones in red.
Dynamic WPM calculation.
Timer-based gameplay.
### Minesweeper
- Objective: Avoid the bombs and clear the grid.
Features:
Multiple difficulty levels (Easy, Medium, Hard).
Flag cells you suspect contain bombs.
### Word Scramble
Objective: Unscramble the letters to guess the correct word.
Features:
Tracks your score and average time per word.
Option to give up and reveal the answer.
### Memory Game
Objective: Match pairs of cards to clear the board.
Features:
Tracks the number of moves and time taken.
### Sudoku
Objective: Solve the Sudoku puzzle by filling in the grid with numbers 1-9.
Features:
Multiple difficulty levels.
Hints available for assistance.
Technologies Used
HTML5: Structure of the games and game hub.
CSS3: Styling for a modern and responsive design.
JavaScript: Game logic and interactivity.
